# Piano samples

These recordings are from the **Salamander Grand Piano** by Alexander Holm, a sampled Yamaha C5,
licensed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).

The files here are the MP3 set (one note every minor third) distributed with the Tone.js examples.
If you publish music made with this sound, credit "Salamander Grand Piano by Alexander Holm".
