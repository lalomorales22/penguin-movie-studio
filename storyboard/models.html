Cheat sheet: which format do I want?

GGUF

The easy one. A single file you can run almost anywhere.
Runs in
Ollama, llama.cpp, LM Studio
Computer
Mac, Windows or Linux, with or without a graphics card
Pick it when
You want to chat with a model and are not sure what computer you will have

MLX

Made for Apple chips, so it is quick on a Mac.
Runs in
LM Studio, mlx-lm
Computer
Apple Silicon Macs only (M1 and newer)
Pick it when
You know it will run on a Mac

Safetensors

The original, as the makers released it.
Runs in
transformers and vLLM for chat models; ComfyUI for image and video models
Computer
Best with an NVIDIA graphics card
Pick it when
You want the untouched original, or an image or video model
What do Q4, Q8, int8 and bf16 mean? They say how tightly the model is squeezed. A smaller number is a smaller file that needs less memory but is a little less sharp. Q4 is the everyday choice, Q8 or 8-bit is nearly the original, and F16 / bf16 is the original itself. The rule of thumb: the file has to fit in the computer's memory with a little room to spare.

Where should I keep these downloads?

Models are big, often 5 to 100 GB each. Pick this computer or an external drive. You can change this any time. Kits are not affected: they always go in the engine's own folder.

Using an external drive? How it should be formatted

exFAT is the one to use: it has no file size limit and works on Mac, Windows and Linux, so the drive can move between computers.

FAT32 (how many USB sticks come) will not work: it cannot hold a file bigger than 4 GB.

APFS is fine if only Macs will ever read the drive. NTFS is fine if only Windows will.
